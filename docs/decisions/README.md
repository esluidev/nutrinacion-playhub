# Decisiones duraderas

Guarda aquí decisiones cuya razón convenga recuperar: límites de componentes, restricciones de datos, contratos o elecciones con consecuencias relevantes. Las decisiones pequeñas pueden quedarse en la tarea o documento del dominio.

Usa [la plantilla de decisión](../../.harness/templates/decision.md) cuando sea útil. Nombra el archivo con un identificador estable y un título corto; respeta una convención existente si ya la hay.

Estados: `propuesta`, `aceptada`, `sustituida`, `descartada`.

Una propuesta redactada por el agente no se convierte en decisión aceptada por existir como archivo. Cuando se sustituya una decisión, identifica la nueva y actualiza la documentación vigente. Conserva las razones históricas si aportan valor; no obligues a leer todas las decisiones para una tarea concreta.
