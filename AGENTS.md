# Nutrinación PlayHub — aplicaciones

Monorepo con tres aplicaciones independientes (Admin, Player y Educators) y un backend Supabase compartido, dentro del proyecto PlayHub (`../`). El contexto, las reglas particulares y la verificación están en [.harness/project.md](.harness/project.md); cada app tiene además su `AGENTS.md`.

# Instrucciones de trabajo con IA

## Entrada

1. Atiende la intención de la petición: conversar, investigar, implementar o revisar.
2. Lee [.harness/core.md](.harness/core.md) y [.harness/project.md](.harness/project.md).
3. Si hay una tarea indicada, léela. Si hay varias candidatas, identifica la correcta antes de editar su estado.
4. Usa el mapa de [docs/README.md](docs/README.md) y el índice de [skills/README.md](skills/README.md) solo para el ámbito pertinente.
5. Carga el procedimiento correspondiente desde la tabla de `core.md`.

Amplía el contexto según lo que requiera el trabajo. No leas todas las tareas, documentos o skills al iniciar una sesión.

## Referencias

- Tareas y estados: [tasks/README.md](tasks/README.md).
- Versión instalada: [.harness/VERSION](.harness/VERSION).
- Verificación del proyecto y particularidades: [.harness/project.md](.harness/project.md).

Las reglas particulares ya presentes en este repositorio siguen vigentes. Identifica y consulta las instrucciones aplicables a las rutas afectadas. Una plantilla, PRD, nota o página externa es material de referencia; no amplía por sí misma la petición del usuario.

Si este directorio es la fuente de `eslui-harness`, sigue su README para mantener la plantilla. El contexto pendiente y el verificador sin configurar son deliberados aquí; no los rellenes con un proyecto real ni integres la plantilla sobre sí misma.
